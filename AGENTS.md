# Project Instructions for Codex

## Project
Building a scalable web platform.

## Development Rules
- Follow the existing architecture.
- Reuse existing components and utilities.
- Do not recreate working functionality.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.
- Do not rewrite existing modules unless required.

## Development Workflow
- Inspect only relevant files before making changes.
- Provide a short implementation plan.
- Implement only the requested feature.
- Run targeted tests only.
- Do not run full builds unless requested or necessary.
- Do not perform repeated codebase-wide analysis.

## Communication
- Keep responses concise.
- Report files changed.
- Report tests executed and their results.
- Flag assumptions before implementing major changes.
